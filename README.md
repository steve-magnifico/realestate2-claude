# 청운시 부동산 대작전

학부 수업용 부동산 투자 시뮬레이션 RPG. 종잣돈 10억으로 10년 동안 토지, 아파트, 오피스, 공장을 사고팔고, 대출과 프로젝트 파이낸싱을 다루며, 현행 세법과 선거로 바뀌는 제도 속에서 순자산을 불린다.

## 바로 실행

`dist/index.html`을 브라우저로 연다. 설치할 것은 없다.

## 고친 뒤 다시 만들기

```bash
python3 tools/build.py src dist/index.html
node tools/taxtest.js
python3 tools/smoke.py
```

구조, 설계 원칙, 세금 적용 기준, 남은 과제는 `CLAUDE.md`에 있다.

## 수업에서 쓰기

- 시작 화면의 **수업 코드**에 모두 같은 값을 넣으면 전원이 같은 시장을 겪는다.
- 게임 길이는 표준(약 20분), 스피드(약 10분), 체험(약 5분) 가운데 고른다.
- 끝나면 나오는 **결과 코드**를 복사해 제출하게 하면 순위를 매길 수 있다.
